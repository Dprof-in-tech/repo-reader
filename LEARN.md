# 📚 Learn - Master Repository Understanding with Repo Reader

Welcome to the Repo Reader learning guide! This document will help you unlock the full potential of AI-powered repository analysis and gamified code exploration.

## 🎯 Learning Objectives

By following this guide, you will learn to:

- **Analyze any GitHub repository** using AI-powered tools
- **Navigate codebases efficiently** through structured learning modules
- **Understand architectural patterns** and design principles
- **Ask intelligent questions** about code using RAG (Retrieval-Augmented Generation)
- **Earn achievements** and track your learning progress
- **Master new frameworks** through interactive walkthroughs

## 🚀 Getting Started

### Your First Repository Analysis

1. **Launch Repo Reader**
   ```bash
   npm run dev
   ```
   Open http://localhost:3000

2. **Enter a Repository URL**
   - Start with a small, well-documented repository
   - Example: `https://github.com/vercel/next.js`

3. **Select Your Experience Level**
   - **Beginner**: Detailed explanations, simpler concepts
   - **Intermediate**: Moderate complexity, some assumptions
   - **Advanced**: Deep dives, complex patterns

4. **Watch the Magic Happen** ✨
   - AI analyzes the repository structure
   - Learning modules are generated automatically
   - Achievements and quizzes are created for you

## 💬 Using the RAG Chat Interface

### What is RAG?
**Retrieval-Augmented Generation** combines:
- **Vector search** for semantic code understanding
- **Full-text search** for exact matches
- **AI generation** for contextual answers

### How to Ask Great Questions

**✅ Good Questions**:
- "How does authentication work in this project?"
- "What database connection pattern is used here?"
- "Explain the error handling strategy"
- "Where is the main entry point?"

**❌ Avoid**:
- "What is authentication?" (too general)
- "Is this code good?" (subjective)
- "Fix this bug" (not a learning question)

### Understanding Chat Responses

Each response includes:
- **Answer**: AI-generated explanation
- **Source Citations**: Relevant code files
- **Line Numbers**: Exact locations in code
- **Context**: Additional helpful information

## 🐛 Troubleshooting Learning Issues

### "I don't understand the learning objectives"
- Read the module description carefully
- Use the RAG chat to ask for clarification
- Start with the file exploration activity
- Review the repository README first

### "Quizzes are too difficult"
- Lower your experience level
- Review the focus files before attempting
- Use the chat to understand concepts first
- Read quiz explanations after each answer

### "I'm stuck on an activity"
- Check the activity instructions
- Explore the suggested files
- Ask the chat for hints
- Skip and return later

### "Progress isn't saving"
- Check browser local storage settings
- Ensure cookies are enabled
- Try refreshing the page
- Contact support if issues persist
